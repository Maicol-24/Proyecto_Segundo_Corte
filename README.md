# Proyecto Segundo Corte

## Proyecto de POO: zoologico

El proyecto modela animales mediante la superclase `Animal` y tres subclases:
`Perro`, `Gato` y `Ave`. Se aplican clases, objetos, herencia, constructores
sobrecargados, `this(...)`, `super(...)` y sobrescritura de `toString()`.

La superclase tiene cuatro atributos privados de tipos diferentes. Cada
subclase agrega cuatro atributos privados de tipos diferentes y define tres
constructores sobrecargados. La clase `Zoologico` crea e imprime ocho objetos
con comentarios que justifican cada constructor.

## Compilar y ejecutar

Desde esta carpeta, ejecutar:

```bash
javac *.java
java Zoologico
```
